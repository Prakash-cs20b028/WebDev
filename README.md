# WebDev

defer is an attribute used in the <script> tag. 
It tells the browser to download the script in the background and 
execute it after the HTML is fully parsed.

async is another attribute that tells the browser to download the script 
in the background and execute it as soon as it's downloaded, without waiting 
for the HTML to finish parsing.

Higher order function are those which takes may takes function as a parameter 
and may return as a function itself.
